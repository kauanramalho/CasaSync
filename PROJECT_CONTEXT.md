# CasaSync

## Objetivo
Sistema colaborativo de tarefas para casal/família, substituindo grupos de WhatsApp para organização.

## Stack
- Frontend: React + TailwindCSS
- Backend: Python + FastAPI
- Banco: PostgreSQL
- ORM: SQLAlchemy
- Auth: JWT

## Estilo visual
- SaaS moderno
- cores pastel
- clean
- cards arredondados
- sidebar lateral
- dashboard moderno
- visual acolhedor e minimalista

## Funcionalidades principais
- famílias/grupos
- tarefas compartilhadas
- categorias
- dashboard
- ranking
- gamificação
- espaço do casal
- integração futura com Google Agenda
- integração futura com IA/agentes

## Objetivo do código
Código limpo, organizado, escalável e profissional para portfólio no GitHub.
